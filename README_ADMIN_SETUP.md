# RIDAA Store — تفعيل لوحة الإدارة الحقيقية

الموقع يعمل كواجهة متجر حتى بدون Backend. لكن لكي تصبح تعديلات الأدمن محفوظة للجميع وآمنة، يجب ربط Supabase مرة واحدة.

## 1) أنشئ مشروع Supabase
- افتح Supabase وأنشئ مشروعًا مجانيًا.
- من SQL Editor افتح ملف `supabase-setup.sql` وانسخه وشغّله كاملًا.

## 2) تأكد من بريد أول مدير
داخل `supabase-setup.sql` تم وضع البريد:
`Almshagbaabdallah@gmail.com`
إذا لم يكن بريدك، غيّره في السطرين الموجودين قرب نهاية الملف قبل تشغيل SQL.

## 3) ضع بيانات الاتصال في الموقع
من Supabase > Project Settings / API انسخ:
- Project URL
- Publishable key أو anon key

ضعهما في `supabase-config.js` بدل القيم التجريبية.
لا تضع service_role key في ملفات الموقع.

## 4) ارفع الملفات إلى GitHub
استبدل ملفات مشروع RIDAA-Store بهذه النسخة، ثم Commit. Cloudflare سيعيد النشر تلقائيًا إذا كان الربط مع GitHub مفعّلًا.

## 5) أنشئ حساب المدير
افتح:
`/admin.html`
ثم اضغط "لدي دعوة مدير وأريد إنشاء حساب" وسجّل بنفس البريد المدعو.
إذا كان تأكيد البريد مفعلًا في Supabase، أكد البريد ثم سجّل الدخول.

## 6) إضافة مدير جديد
من لوحة الإدارة > المدراء والصلاحيات:
- اكتب البريد
- اختر Admin أو Super Admin
- أضف الدعوة
بعدها صاحب البريد يفتح `/admin.html` ويختار إنشاء حساب المدير.

## ما الذي يمكن تعديله من لوحة الإدارة؟
- إضافة/حذف/تعديل المنتجات
- الأسعار والأسماء والتصنيفات والوصف
- رفع صور وحذف الصور المرفوعة
- اسم المتجر، الهاتف، واتساب، البريد والعنوان
- روابط السوشال ميديا
- الشريط العلوي
- عناوين ونصوص الصفحة الرئيسية
- محتوى قسم التفصيل وقصة المتجر
- إضافة وإزالة المدراء (Super Admin)

## ملاحظة الصور
الصور المرفقة داخل `assets/products/model-set` موحّدة على نفس الموديل وبخلفية استوديو متناسقة. ويمكن لاحقًا استبدال أي صورة من لوحة الإدارة بدون تعديل الكود.
